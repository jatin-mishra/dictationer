Dictationer interactive prototype
Serve this folder using a static HTTP server.
Books, laps, workflow reports, immutable published editions and draft locks are saved in browser local storage.
Publishing creates separate read-only editions. Locking a book locks all chapters/pages; unlocking preserves child locks. Editing requires book, chapter and page unlocked.
English and Hindi UI. Voice, publishing and cover generation are simulated. Proofreading uses limited local demo rules rather than a backend language service.
